# PAA V0.8 RC1 — User Acceptance Test

This release candidate freezes the core 1–9 operator grammar for UAT and adds guided onboarding, anonymous tester sessions, interruption-safe assessment, in-context feedback, completion tracking, and UAT export. The purpose of this build is to discover where real users become confused, abandon the flow, disagree with classifications, or encounter defects—not to maximize agreement with PAA.

# PAA V0.8 RC1 — Pythagorean Arithmosophic Anamnesis

A cross-platform Expo / React Native research prototype for treating number 1–9 as an operational grammar and testing numerical hypotheses against observed human behavior.

## The experience

**Discover** — calculate a birth-root hypothesis and compare it with the balanced 36-item Behavioral Operator Instrument.

**Observe** — record lived behavior through Quick Anamnesis or the rigorous five-slot record: CONDITION → OBJECT → ACTION → TRANSFORMATION → RESULT.

**Test** — commit a prospective operator prediction before an event resolves, freeze it, then score the observed result without rewriting the forecast.

## Run locally

```bash
npm install
npx expo start
```

On Windows PowerShell systems that block npm.ps1, use:

```powershell
npm.cmd install
npx.cmd expo start
```

Then scan the QR code with Expo Go, or press `w` for Expo Web.

## Epistemic status

PAA V0.8 RC1 is an experimental interpretive and research framework, not a clinical, diagnostic, or validated psychological instrument. Numerical glyphs generate hypotheses; behavioral records and prospective tests are kept as distinct evidence layers. Divergence is retained rather than explained away.
