# Tester Handoff — V0.10

For a shared testing device:

1. Researcher opens **Researcher View**.
2. Tap **Prepare device for next tester**.
3. Confirm the reset.
4. Hand the device to the next tester at the onboarding screen.

The reset removes only the current tester session, unfinished BOI draft, and latest-profile display. It preserves historical UAT sessions, feedback, final surveys, prospective trials, and research records for later export.

Do not coach the tester during the BOI. If a question is confusing, use the in-app confusion report rather than explaining which operator an answer represents.
